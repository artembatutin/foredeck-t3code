# Foredeck brand assets

`appicon.png` is generated from the archived Foredeck vector source preserved in
`assets/fd/branding/appicon.source.html`. Run `vp run icons:export` to regenerate
it together with the desktop, web, and mobile icons.

The shared `fd/branding` entry reuses the archive's monochrome anchor geometry for
in-app marks, including its original source notice. No provider assets or fonts are copied.
